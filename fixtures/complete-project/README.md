# RepoPilot Sample

A complete, well-documented sample project used by RepoPilot tests.

## Install

```sh
pnpm install
```

## Environment

Copy `.env.example` to `.env` and fill in the values.

## Run

```sh
pnpm dev
```

## Test

```sh
pnpm test
```

## Demo

Live demo: https://demo.example.com

## Architecture

- `src/index.ts` — entrypoint
- `src/api/` — HTTP layer
- `src/db/` — data layer
- `tests/` — Vitest suite
